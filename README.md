# sestationreport V2.0.0
Web Scraping Python app to collect info for this year's Missouri QSO 
Party 1x1 SE Stations for SHOWME and MISSOURI awards. The  data is 
collected from the website 1x1callsigns.org and saved to the current
year MOQP Scores database. Reports in HTML and csv are generated showing
the owner of each 1x1 callsign. Details about each operator are also
collected to assist in managing the event.

##Usage

```
sestationreport --calls CALLSIGNLIST --start STARTDATE --end ENDDATE --type TYPE

Generate a report of 1x1 Special Event callsigns for the event starting on STARTDATE and ending on
ENDDATE using format TYPE. The website http://www.1x1callsigns.org/ will be accessed to look up details
for each 1x1 callsing in CALLSIGNLIST.

optional arguments:
  -h, --help            show this help message and exit
  -c CALLS, --calls CALLS
                        The list of callsigns to look up. Omit to use the default SHOWME and MISSOURI
                        lists.
  -s STARTDATE, --startdate STARTDATE
                        The starting date for the special event. Omit this to use the default dates in
                        mqpsesdefs.py
  -e ENDDATE, --enddate ENDDATE
                        The ending date for the special event. Omit this to use the default dates in
                        mqpsesdefs.py
  -t {csv,html}, --rtype {csv,html}
                        The report type (csv or html).
  -d, --display         Display the browser and show activity. Default is to run "headless" (no
                        display).
  -n, --nodatabase      Lookup the list of callsigns, but skip writing or persisting the results in the
                        MOQP database.
  -v, --version         Display version and exit
```

V2.0.0 adds mqpsestats - Intended for us after logs have been submitted,
statistics are gathered to measure performance of each 1x1 station. The
data may be displayed in CSV and HTML format.

##Usage:
```
mqpsestats --inputpath <path to logfile> --fullreport

Show statistic for the Special Event 1x1 stations in the Missouri QSO Party.

optional arguments:
  -h, --help            show this help message and exit
  -v, --version         show program's version number and exit
  -i INPUTPATH, --inputpath INPUTPATH
                        Load details for 1x1 operators/stations from the .csv file generated by the
                        status1x1 web scraper. By default this would be operators.csv. If the filename
                        is INIT, an empty table will be created. Note that this option deletes and
                        replaces what is currently in the database, so back it up using phpMyAdmin or
                        mysqldump before running.
  -c CALLSIGN, --callsign CALLSIGN
                        Fetch details for CALLSIGN from MOQP database. Entering 'allcalls' will run the
                        report on all the 1x1 calls in the database.
  -l LOGID, --logid LOGID
                        Add a link to the SES callsign station log if the log exists in the database.
                        Entering allcalls will add or update log ID for all SES calls in the database.
  -t {csv,html}, --reportType {csv,html}
                        Set report type for output. Only valid if more than one report output type is
                        avaible. Options are: csv (Comma Separated Variables) for printing or for
                        import to a spreadsheet, or html for web page use. default value is csv

```
